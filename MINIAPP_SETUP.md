# Как сделать из календаря настоящее мини-приложение MAX

Мини-приложение в MAX — это обычная HTTPS-страница, URL которой привязан к боту
на платформе MAX для партнёров. В коде бота этот URL не указывается: MAX берёт
его из настроек бота.

```
GitHub Pages (HTTPS-страница)
        ↓ URL
business.max.ru → бот → Настройки → ссылка на мини-приложение
        ↓
MAX открывает страницу внутри себя (кнопка open_app / кнопка в чате)
```

## Шаг 1. Выложить страницу на HTTPS

Нужен постоянный адрес. Самый простой вариант — GitHub Pages (бесплатно).

1. В PyCharm: **Commit** → отметить `miniapp/index.html` (и остальные файлы) →
   **Commit and Push**. Из терминала push не пройдёт: нет сохранённых учётных данных.
2. Открой репозиторий: https://github.com/maxevgst19/TimeBalanceBot
3. **Settings → Pages** (в левом меню).
4. **Build and deployment → Source: Deploy from a branch**.
5. **Branch: `main`**, папка **`/ (root)`** → **Save**.
6. Через 1–2 минуты проверь в браузере:
   `https://maxevgst19.github.io/TimeBalanceBot/miniapp/`
   Должен открыться календарь (если 404 — подожди ещё минуту).

Важно:

- Репозиторий должен быть **публичным**. Для приватных репозиториев GitHub Pages
  требует платный план.
- URL должен быть постоянным. Временный туннель (`lhr.life`) для привязки не годится.
- Другие варианты хостинга: VK Cloud (есть готовый хостинг мини-приложений MAX),
  Yandex Cloud, Cloudflare Pages.

## Шаг 2. Привязать URL к боту

1. Открой https://business.max.ru/self и войди в свой аккаунт.
2. Раздел **Чат-боты** → **Перейти**.
3. Выбери бота **39_Идея_фикс** (`@ideya_fiks_39_bot`).
4. Нажми **⋮ → Настройки**.
5. В поле для ссылки на мини-приложение вставь URL из шага 1.
6. Выбери вид кнопки: **Открыть** (можно «Старт», «Играть» или без названия).
7. Нажми **Сохранить**.

Требования к URL (из документации MAX):

- только `https://`
- не длиннее 1024 символов
- без пробелов
- ссылка должна открываться

То же самое можно сделать в мини-приложении «MAX для бизнеса»:
https://max.ru/business_bot?startapp

## Шаг 3. Проверить в MAX

1. Открой чат с ботом `@ideya_fiks_39_bot`.
2. Внизу чата появится кнопка запуска мини-приложения — нажми её.
3. Календарь должен открыться **внутри MAX**, без браузера.

Ещё можно открыть напрямую:
`https://max.ru/ideya_fiks_39_bot?startapp`

## Шаг 4. Переключить бота на режим мини-приложения

После привязки URL поменяй в `.env`:

```env
MINIAPP_MODE=mini_app
```

Затем перезапусти:

```powershell
.venv\Scripts\python code.py
```

В этом режиме бот присылает кнопку `open_app` — она открывает привязанное
мини-приложение внутри MAX. Туннель больше не нужен, `code.py` запускает только бота.

## Если что-то не работает

| Симптом | Причина |
|---|---|
| Кнопки в чате нет | URL не сохранён в business.max.ru или выбрана не та кнопка |
| Открывается пустое окно | URL не привязан / страница отдаёт 404 |
| Открывается браузер, а не MAX | У бота не настроено мини-приложение, сработала обычная ссылка |
| 404 на GitHub Pages | Pages ещё собирается или выбран неверный путь (`/miniapp/`) |
| Страница не открывается | Ссылка не HTTPS или содержит пробелы |

## Что дальше

Календарь хранит задачи в `localStorage` — они остаются на устройстве
пользователя. Чтобы синхронизировать их между устройствами, нужен бэкенд
(контракт уже описан в `openapi.yaml`).
