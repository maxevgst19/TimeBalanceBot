# TimeBalance Bot для MAX

Мини-приложение для школьников 12–17 лет внутри мессенджера MAX: показывает,
помещаются ли дела в реальный день, и предлагает «План Б», когда времени не
хватает. Чат-бот — точка входа в приложение.

Подробнее: [PROJECT_CONCEPT.md](PROJECT_CONCEPT.md),
[DESIGN_STANDARD.md](DESIGN_STANDARD.md).

## Что уже есть

| Часть | Файл | Статус |
|---|---|---|
| Чат-бот MAX: `/start`, `/help`, кнопка запуска приложения | `bot/max_bot.py` | готов |
| Мини-приложение: «Сегодня», «Неделя», «Профиль», «План Б», добавление дел | `miniapp/` | готов (данные в localStorage) |
| Концепция и дизайн | `PROJECT_CONCEPT.md`, `DESIGN_STANDARD.md` | документы |

## Запуск бота

1. Получи токен: [business.max.ru](https://business.max.ru/self) → **Чат-боты** →
   нужный бот → **⋮ → Настройки** → значок копирования у поля с токеном.
2. Впиши токен в файл **`.env`** в корне проекта:

   ```env
   MAX_BOT_TOKEN=вставь_токен_сюда
   ```

3. Установи зависимости и запусти:

   ```powershell
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   .venv\Scripts\python code.py
   ```

`code.py` — точка входа: поднимает демо-хостинг мини-приложения и запускает бота
из `bot/max_bot.py`.

> **Демо-хостинг.** Если `MINIAPP_URL` не задан, `code.py` сам поднимает локальный
> сервер с `miniapp/` и HTTPS-туннель через [localhost.run](https://localhost.run)
> (обычный `ssh`, без регистрации). В консоли появится адрес вида
> `https://xxxx.lhr.life` — на него ведёт кнопка в боте. Адрес живёт, пока
> запущен `code.py`; при перезапуске он меняется.

> **Сертификаты Минцифры.** MAX API работает с сертификатами Минцифры. Они уже
> лежат в `certs/` (`russian_trusted_root_ca.pem`,
> `russian_trusted_sub_ca.pem`), бот подключает их автоматически вместе с
> системными. Без них будет ошибка `CERTIFICATE_VERIFY_FAILED`.

После запуска в логе появится `Бот: <имя> (@<username>)` — значит, подключение к
MAX Bot API работает.

## Подключение мини-приложения

Режим кнопки задаётся переменной `MINIAPP_MODE` в `.env`:

| Режим | Что делает кнопка |
|---|---|
| `mini_app` (по умолчанию) | `open_app` — открывает мини-приложение **внутри MAX** |
| `link` | обычная ссылка, открывается в браузере (для быстрого теста; `code.py` сам поднимает туннель) |

### Как сделать настоящее мини-приложение внутри MAX

1. Выложи папку `miniapp/` на **HTTPS**-хостинг (GitHub Pages, VK Cloud, Yandex Cloud). URL должен быть постоянным.
2. Открой [business.max.ru](https://business.max.ru/self) → **Чат-боты** → нужный бот → **⋮ → Настройки**.
3. Вставь URL мини-приложения в поле для ссылки, выбери кнопку **«Открыть»** и сохрани.
4. Впиши этот же адрес в `.env` как `MINIAPP_URL=https://...`.

После этого кнопка `open_app` и кнопка запуска в чате MAX будут открывать
приложение внутри мессенджера, без браузера и без туннеля.

> Важно: `open_app` не содержит URL. Адрес мини-приложения хранится только в
> настройках бота на стороне MAX, поэтому привязать его из кода нельзя.

## Структура

```text
code.py                 — точка входа: демо-хостинг мини-приложения + бот
bot/max_bot.py          — бот MAX: long polling, /start, /help, кнопка запуска
bot/miniapp_host.py     — локальный сервер miniapp/ + HTTPS-туннель для демо
certs/                  — сертификаты Минцифры для подключения к MAX API
miniapp/index.html      — собранная страница (встроенный сжатый CSS)
miniapp/app.min.js      — собранный JS
miniapp/src/            — исходники: index.html, styles.css, app.js
miniapp/calendar.html   — прежний календарь (сохранён как есть)
tools/build_miniapp.py  — сборка miniapp/index.html и app.min.js
.env                    — токен бота (не попадает в git)
```

## Фронтенд

Интерфейс сделан по `DESIGN_STANDARD.md`: светлая «тетрадь», токены цветов,
крупная шкала дня и спокойные формулировки.

- **Сегодня** — карточка «Сейчас», конфликт с точным дефицитом минут, шкала дня
  (занятия, дорога, отдых, задания, свободные окна), итог дня.
- **Неделя** — семь строк с нагрузкой и пометкой конфликта.
- **План Б** — варианты перестройки, изменения и остаточный риск до применения.
- **Профиль** — граница учебного дня, перерыв после школы, уведомления, сброс данных.
- **Добавить** — нижний лист: «Задание» или «Занятие», быстрая проверка полей.

Приложение стартует пустым: демо-дел нет, пользователь добавляет свои. Кнопка
«Сбросить данные» очищает дела и занятия и возвращает настройки по умолчанию.

Исходники лежат в `miniapp/src/`, а `miniapp/index.html` и `miniapp/app.min.js`
собираются из них. Правь `src/`, затем запускай:

```powershell
.venv\Scripts\python tools\build_miniapp.py
```

Сборка нужна из-за бесплатного туннеля: он обрывает большие ответы. CSS
встраивается в страницу, поэтому получается два запроса вместо трёх, а после
gzip каждый ответ меньше 10 КБ. Если JS не загрузился с первого раза, страница
сама пробует ещё дважды и показывает кнопку «Повторить» — стили при этом видны
сразу, потому что они внутри HTML.

Данные хранятся в `localStorage`, расчёт плана выполняется на клиенте по правилам
из `PROJECT_CONCEPT.md`.

Локальный предпросмотр (показывает уже собранную версию):

```powershell
cd miniapp
python -m http.server 8080
```

## Ограничения MAX

- Подключение к платформе доступно юрлицам, ИП и самозанятым — резидентам РФ, бот проходит модерацию.
- Long polling подходит для разработки и демо; для production нужен Webhook (`POST /subscriptions`).
- Запросы идут на `https://platform-api2.max.ru`; при проблемах с TLS добавь сертификат Минцифры в доверенные.
