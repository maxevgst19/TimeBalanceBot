# TimeBalance

**TimeBalance** — мини-приложение в MAX, которое показывает школьнику его реальный день:
занятия, дорогу, задания, свободные окна и отдых. Когда дела не помещаются, оно
показывает дефицит времени на наглядной шкале и предлагает несколько вариантов
«Плана Б».

В репозитории находятся мини-приложение, REST API и чат-бот MAX.

- Концепция продукта — [`PROJECT_CONCEPT.md`](PROJECT_CONCEPT.md)
- Контракт API — [`openapi.yaml`](openapi.yaml)
- Стандарт интерфейса — [`DESIGN_STANDARD.md`](DESIGN_STANDARD.md)

## Что делает мини-приложение

| Экран | Что видит пользователь |
|---|---|
| **Сегодня** | Карточка «Сейчас» с одним выполнимым шагом, вертикальная шкала дня, свободные окна и итог: сколько свободно и сколько запланировано. Если дел не хватает — карточка «Не хватает N минут» с причиной и кнопкой «Собрать План Б». |
| **Неделя** | Семь дней с суммарной занятостью, свободными минутами и отметками конфликтов. |
| **План Б** | 2–3 варианта перестройки дня. Каждый показывает, что переместится или разделится, и **оставшийся дефицит до нажатия «Применить»**. После применения план пересчитывается. |
| **Добавить** | Короткая форма: для занятия — название, начало, конец; для задания — название, срок, длительность. Дополнительно — повторение, дорога, переносимость, делимость. |
| **Профиль** | Личные границы: время окончания учебных дел, перерыв после школы, часовой пояс, уведомления, «Мои данные» и «Удалить данные». |

Главное обещание продукта — показать, что дел **не помещаются**, до того как вечер
уже сорван, и предложить выбор, а не «постараться сильнее».

## Как считается план

Алгоритм — работа интервалами без ИИ (`app/planning/engine.py`, раздел 9
`PROJECT_CONCEPT.md`):

1. строятся занятые интервалы: события, дорога до/после, перерыв после школы;
2. внутри `[начало учебного дня, окончание учебных дел]` ищутся свободные окна;
3. задачи раскладываются по окнам по срочности: делимые — кусками, неделимые —
   только в окно нужной длины;
4. неразмещённые минуты превращаются в конфликт с точным числом и причиной:
   `time_shortage` (общий дефицит), `deadline` (задача не влезает в окно),
   `overlap` (пересечение занятий или дороги);
5. из конфликта собираются варианты «Плана Б» — каждый сначала применяется к копии
   данных, план пересчитывается, и пользователю показывается остаточный дефицит
   (`app/planning/alternatives.py`).

Отдых защищён: задачи никогда не ставятся после `day_end`, а обязательный перерыв
после школы — такой же занятый блок, как урок.

## Запуск

Фронтенд и API теперь обслуживаются одним FastAPI-сервером. После запуска
откройте `http://127.0.0.1:8000/` (переход на `/miniapp/`). В обычном браузере
мини-приложение работает как локальное демо. При запуске внутри MAX оно получает
подписанное `window.WebApp.initData`, обменивает его на сессию через
`/api/v1/auth/max` и сохраняет дела и настройки в PostgreSQL через API. Для MAX
нужен публичный HTTPS-адрес этого же сервера и `MAX_BOT_TOKEN` в окружении.

```bash
docker compose up -d postgres  # локальная PostgreSQL на порту 5433
pip install -r requirements.txt

cp .env.example .env      # вписать MAX_BOT_TOKEN, MINI_APP_URL и DATABASE_URL
python code.py            # http://127.0.0.1:8000
```

Для локального Docker задайте в `.env`:
`DATABASE_URL=postgresql://timebalance:timebalance_dev@127.0.0.1:5433/timebalance`.
Таблицы создаются при первом запуске. Старый SQLite-файл не удаляется.

Для Render создайте PostgreSQL и передайте его **Internal Database URL** в
`DATABASE_URL` веб-сервиса. Команда запуска:

```bash
uvicorn app.main:app --host 0.0.0.0 --port $PORT
```

Swagger UI — `http://127.0.0.1:8000/docs`, спецификация — `/openapi.json`
(пути относительны к `/api/v1`, как в `openapi.yaml`).

### Переменные окружения

См. [`.env.example`](.env.example). Основные:

- `MAX_BOT_TOKEN` — токен бота; без него работает только API, бот и уведомления отключаются;
- `MINI_APP_URL` — ссылка, которую бот отдаёт по кнопке;
- `DAY_START` / `профиль пользователя.day_end` — границы учебного дня;
- `DATABASE_URL` — строка подключения PostgreSQL; без неё сервер не запускается.

**Токен и другие секреты в репозиторий не попадают:** `.env` в `.gitignore`,
`.env.example` содержит только плейсхолдеры.

## Чат-бот — проводник

Бот не планирует: его роль ограничена (раздел 8 концепции).

- `/start` — короткое описание продукта и кнопка **«Открыть мини-приложение»**;
- `/help` — список команд;
- служебные кнопки — ссылка на приложение и краткое объяснение, как оно работает;
- уведомления от сервера — редкие и полезные: «Среда перегружена: не хватает
  45 минут. Открой План Б» и напоминание за 15 минут до события. Одна причина —
  одно сообщение в сутки (дедупликация в `notifications_sent`).

Один школьник в боте и в мини-приложении — одна запись: бот заводит профиль по
`user_id` из MAX, а мини-приложение связывается с ним при первом входе по
подписанному `initData`.

## API

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/auth/max` | Обмен проверенного `initData` на сессию |
| GET/PATCH | `/me` | Профиль и личные границы |
| DELETE | `/me/data` | Полное удаление данных пользователя |
| GET/POST | `/events` | Уроки, кружки и другие занятия (с повторениями) |
| PATCH/DELETE | `/events/{eventId}` | Изменить или удалить событие |
| GET/POST | `/tasks` | Задания со сроком и длительностью |
| PATCH/DELETE | `/tasks/{taskId}` | Изменить, закрыть или удалить задание |
| GET | `/plan` | План: блоки, конфликты, свободное и запланированное |
| GET | `/plan/next-action` | «Что делать сейчас» |
| POST | `/plan/alternatives` | Варианты «Плана Б» с последствиями |
| POST | `/plan/alternatives/{id}/apply` | Применить вариант и пересчитать план |

Все даты — ISO 8601 с часовым поясом, длительности — в минутах, диапазон плана —
не больше 31 дня. Ошибки всегда в формате `{"code", "message", "details"}`.

```bash
python scripts/check_openapi.py
```

Тесты покрывают подпись `initData` (подделка, дубликаты параметров, срок),
свободные окна с учётом дороги и перерывов, раскладку задач, дефицит, пересечения,
повторения, «Что делать сейчас» и сквозной сценарий API — включая получение и
применение варианта «Плана Б».
